## Purpose

This file identifies the status of legacy artifacts preserved in this repository so that direct-file access does not silently convert historical implementation assumptions into current IC DAO commitments.

The repository preserves history. It does not define current product, economic, governance, regulatory, investor-access or engineering policy.

The historical status of this repository does **not** mean that IC DAO abandoned:

- real-world assets or real estate;

## Machine-readable metadata warning

`assets/token-metadata.json` is intentionally preserved as historical evidence and has **not** been rewritten to simulate a current metadata implementation.

It contains historical token framing and a placeholder image URL using `YOURUSERNAME`. Machine consumers, integrations and engineering work must **not** treat this file as current canonical token metadata, a verified current registry entry, or proof of current token utility/governance semantics.

Any future token representation or metadata implementation must start from:

current requirement
→ current Solana standard / infrastructure check
→ REUSE / INTEGRATE / ADAPT decision
→ approved implementation in the appropriate current engineering repository.
